# Как добавлять проекты

## Новый проект

1. Скопируйте подходящий файл из `cases/`:
   - `_template-print.html` — полиграфия;
   - `_template-presentation.html` — презентации;
   - любой существующий кейс — сайт или приложение.
2. Переименуйте копию латиницей, например `annual-report.html`.
3. Замените текст в квадратных скобках и плейсхолдеры на реальные материалы.
4. Создайте папку `img/annual-report/` и положите туда изображения в WebP или AVIF.
5. Добавьте карточку проекта в `projects.html`. На главной сохраняйте только семь выбранных карточек.

## Категории для фильтра

У карточки должны быть оба атрибута:

```html
<a class="card proj c6" href="cases/annual-report.html"
   data-project-card data-category="print">
```

Допустимые значения:

- `sites` — сайты;
- `apps` — приложения;
- `print` — полиграфия;
- `presentations` — презентации.

Числа внутри кнопок фильтра обновляются автоматически.

## Материалы кейса

- Обложка карточки: WebP/AVIF, желательно 1600 × 1200 px.
- Изображения в кейсе: WebP/AVIF шириной 1600–2200 px.
- PDF до 15–20 МБ можно хранить в папке `files/`.
- Тяжёлые PSD, INDD и PPTX лучше разместить в облачном хранилище и дать ссылку.
- Для PPTX полезно добавить PDF-превью: оно открывается прямо в браузере.
- Для презентации можно добавить короткое MP4-видео с перелистыванием слайдов.

Перед публикацией удалите `<meta name="robots" content="noindex">` из готового кейса.
